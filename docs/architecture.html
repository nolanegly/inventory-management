Filter System

4 Global Filters — shared via useFilters.js singleton
Time Period
→ month param
Supports month strings & quarters (Q1-2025)
Warehouse
→ warehouse param
All views except Demand & Backlog
Category
→ category param
Inventory, Orders, Dashboard
Order Status
→ status param
Orders & Dashboard only

Values of 'all' are stripped before building URLSearchParams — the backend receives only active filters.

Data Flow — Filter Selection to UI Update

1
User selects a filter in FilterBar.vue

Dropdown change updates a singleton ref in useFilters.js (shared across all components via module scope)

2
View component reacts

Each view watch()es the filter refs. On change, calls getCurrentFilters() which maps selectedLocation → warehouse, selectedPeriod → month

3
api.js fires an axios GET request

Builds URLSearchParams, omitting any filter still set to 'all'. Sends to http://localhost:8001/api/...

4
FastAPI filters in-memory data

apply_filters() chains warehouse → category → status checks. filter_by_month() handles plain month strings and quarter notation (Q1-2025)

5
Pydantic validates & serializes the response

Response models ensure shape consistency before JSON is returned to the client

6
Vue re-renders

axios response updates a reactive ref → computed properties re-evaluate → template re-renders automatically
